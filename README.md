# Strike

An open-world helicopter action game in the spirit of Desert, Jungle and Urban Strike.
One self-contained web page: play it at **https://squatchfighter.github.io/strike/** in any browser, desktop or phone.

- **Fly / drive:** WASD or arrows (touch: left half of the screen)
- **Fire:** J / K / L (touch: A / B / C)
- **Get in or out of vehicles:** E
- **Map:** Tab · **Zoom:** Z · **Campaign maps:** N
- **Two players:** 2 PLAYERS → HOST A GAME → SHARE. The other player taps the link and shares the reply back.

**Campaign:** 30 maps to conquer, unlocked in order. Progress saves automatically; MAPS → CLOUD SAVE shares it between devices.

The source and art tools live in a private working folder; this repository holds only the built game.
Map data for REAL PLACE © OpenStreetMap contributors.
